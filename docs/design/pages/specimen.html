Critical apparatus

A hadith page is a scholarly edition. The text is read; everything that argues about the text is set as apparatus — smaller, coded, in a different face. Every number below comes from the real DDL.

Specimen A · the common case

Ṣaḥīḥ al-Bukhārī 1

Every narrator resolves and Ibn Hajar grades all of them ثقة, so all six weights tie at 0.95 and no single link is the weak one. This is what most of the corpus looks like — the average is 0.836 and only thirteen distinct values occur. The apparatus has to stay interesting when nothing is wrong, and it must not invent a weakest link where the data has a tie.

Vocabulary

Seven node states, and why grey is not red

This sentence belongs on the product screen, not only here. A red node reports a verdict a classical scholar wrote centuries ago. It is never Ilham's own judgement, and it never means the page is broken. Put that in words next to any red state a reader can see.

The six grades, weakest to strongest: متروك abandoned · ضعيف weak · لين soft · مقبول acceptable · صدوق truthful · ثقة trustworthy. Never show these words untranslated as a bare axis label.

The schema keeps graded, named-but-ungraded, and unnamed apart, and it splits "no link" into three different reasons. The tempting mistake is one good-to-bad ramp, which renders "we do not know" as "this is bad" — a claim the data never makes. Shape carries the state as well as colour, so nothing depends on colour alone.

  • Graded, strong res A · B

    A profile matched and a scholar graded them well. The weight is the stricter of the two scholars.

  • Graded, weak res A · B

    A grade that lowers the weight. Red reports a classical verdict, never ours.

  • Lowest weight

    The minimum in this sanad, shown only when one link holds it alone. On a tie, nothing is ringed.

  • Named, not graded 0.50

    Resolved, but no scholar graded them. Neutral, and above مقبول-less-anʿana on the scale. Absence of a grade is not a bad grade.

  • Ambiguous res C

    The name fits more than one narrator. We know the name, not the person, so it does not link.

  • Unresolved res X

    No profile matched at all. The raw string stays on screen. The loader never removes the row.

  • Placeholder

    The source itself records an unidentified narrator. A square, because this gap is a different kind from an unmatched name.

  • Compiler

    Always last, always excluded, always res X in the data — and never a failure. Drawn in ink to sit outside the grade scale.

Foundations

Colour

Bone, not parchment: a cool ground with a faint green cast, matched in temperature to a green-black ink. Three hues carry meaning and nothing else. Red follows the manuscript rule for rubrication — it marks what you must not miss, and it appears nowhere decorative.

Foundations

Icons

Phosphor, regular weight, one stroke width, drawn on a 24px box at three token sizes. Never emoji — they are font-dependent and no design token reaches them. An icon beside a visible label is decorative and takes aria-hidden="true". An icon alone in a control gives the control its accessible name.

Sizes16px inline with text · 20px in navigation and buttons · 24px only as a page-level mark.

Never used forGrade, resolution and chain state are carried by the node vocabulary, not by icons. One visual language per idea.
